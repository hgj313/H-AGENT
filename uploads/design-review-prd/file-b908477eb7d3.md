## 1. 引言

### 1.1 背景

业主单位：吉盛园林工程管理中心。

### 1.2 目的

通过项目里程碑看板辅助管理者对公司在建项目的里程碑节点进行管控，以及为年终项目评优提供数据计算服务。

### 1.3 范围

| 维度 | 说明 |
|------|------|
| 使用对象 | 吉盛工程中心总经理、吉盛工程各区域总经理、吉盛工程中心项目管理专员 |
| 应用场景 | 周度、月度项目里程碑节点管控 |

---

## 2. 系统概述

本次需求为吉盛工程中心提出，依托桫椤数据库数据，提供更便捷的吉盛工程项目里程碑可视化看板，依附于现有 ERP 系统。

### 2.1 功能菜单路径

```
报表管理（一级 TAB）
  └── 吉盛园林
       └── 管理报表
            └── 里程碑看板（不渲染 TAB）
```

### 2.2 系统需求概述

#### 2.2.1 项目状态展示与预警推送

展示各个区域的里程碑项目状态，对延期项目推送相关负责人。

> **注：** 更像是数据搬运 + 聚合显示，预警及延期推送系统已经实现。

#### 2.2.2 查询功能

提供以下多维度查询能力：

- 按区域查询
- 按年份时间查询
- 按项目经理查询

## 7. 数据库设计

### 7.1 新增数据表

新增一张表用于存储按时完成率、延时完成率、延期天数等数据，用于年终进行数据统计。

**表名：** `construction_project_milestone_info`（待定）

### 7.2 实体：里程碑任务项

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INT | 自增主键 |
| `project_id` | INT | 指向 `project` 表的外键 |
| `technical_plan_id` | INT | 指向 `technical_plan` 表的外键 |
| `region` | STRING | 所属项目的所属区域 |
| `project_status` | STRING | 所属项目的项目状态 |
| `on_time_completion_rate` | DECIMAL | 及时完成率 |
| `delay_completion_rate` | DECIMAL | 延期完成率 |
| `overall_completion_rate` | DECIMAL | 总体完成率 |

## 8. 界面设计

### 8.1 界面概述

仿照**道合里程碑看板**进行设计。

> [图片：界面原型图]

### 8.2 里程碑显示形式

#### 方案一：横向平铺式设计

参照道合里程碑看板，横向平铺式设计。

| 优点 | 缺点 |
|------|------|
| 可多项目纵向对比 | 里程碑数目过多时需左右横向滚动滚动条，无法查看单一项目的里程碑节点全貌 |

> [图片：横向平铺式示意]

#### 方案二：嵌套表格折叠式设计

使用嵌套表格，折叠式设计。

| 优点 | 缺点 |
|------|------|
| 可总览单项目里程碑节点 | 难以针对同一里程碑节点进行多项目纵向对比，需要手动点开嵌套表格 |

> [图片：嵌套表格折叠式示意]

#### 方案三：两者结合（推荐）

同时保留前两者的优点。

| 优点 | 缺点 |
|------|------|
| 同时保留横向对比与单项目总览的能力 | 无明显缺点 |
