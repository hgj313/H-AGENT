## Web 部署 (下午)
用户要求打包部署到本地，做前端界面上传附件，输出表格文件。

### 实现内容
1. `web_app/server.py`: FastAPI 后端
   - POST /api/upload: 接收多PDF，调用 insurance_agent 提取，返回JSON
   - GET /api/download/csv: 导出 CSV (UTF-8-BOM)
   - GET /api/download/xlsx: 导出 Excel (openpyxl, 带表头样式/增减保着色)
   - GET /api/policy-library: 查看保单库
   - GET /: 返回前端页面
   - 端口 8765, host 0.0.0.0
2. `web_app/static/index.html`: 前端界面
   - 拖拽/点击上传多PDF
   - 处理进度+日志显示
   - 结果表格展示 (按文件分组, 增保红色/减保蓝色)
   - 下载 CSV/Excel 按钮
3. `启动保险单识别系统.bat`: 一键启动脚本
