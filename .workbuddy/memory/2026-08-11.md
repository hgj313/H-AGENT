## 公司系统API对接 - 保险数据导入

### 登录接口（已解决）
- **正确端点**: `POST http://47.108.166.14:8081/api/doLogin`（之前错误用了 `/doLogin`）
- **请求格式**: JSON `{"userName":"chenxueqin","password":"1234","encrypted":false}`
- **关键字段**: `userName`（不是 username）、`password`、`encrypted`（设为 false 用明文密码）
- **返回**: `{"data":true,"success":true}`，Set-Cookie 中含 JSESSIONID，30分钟有效

### 签名机制发现
- `findInsurance/page` 等查询接口需要 `X-Timestamp / X-Nonce / X-Sign` 签名头
- **importExcel 和 exportExcel 接口豁免签名**，直接用 cookie 即可访问
- Swagger 文档地址: `http://47.108.166.14:8081/v2/api-docs`（7.5MB JSON）

### 数据导入（成功）
- **端点**: `POST /api/labor/warehousing/importExcel`
- **格式**: multipart/form-data, 参数名 `file`
- **模板文件**: `最新保险数据下载模板.xlsx`（1055行，7列：姓名/证件号码/年龄/打卡项目/所属班组/所属公司/劳务分类）
- **结果**: `{"data":"导入成功!","success":true}`

### 导出接口（可用）
- `GET /api/labor/warehousing/exportExcel?punchDate=YYYY-MM-DD&current=1&pageSize=20`
- 返回 `attachment;filename=打卡记录.xlsx`
- 需要 current 参数（int类型不能为null）

## 新增模块：会话管理 + Excel同步

### SessionManager (`insurance_agent/infrastructure/session_manager.py`)
- 定时登录公司系统续期 JSESSIONID，25分钟刷新一次（会话30分钟有效）
- 后台 threading.Timer daemon 线程，随服务启停
- `login()` / `get_session()` / `is_active()` / `start()` / `stop()`
- 支持 context manager (`with SessionManager(...) as mgr:`)

### Excel同步 (`insurance_agent/tools/excel_sync.py`)
- `sync_excel_with_extraction(excel_path, extraction_results, output_path)`
- 逻辑: 减保→从Excel删除(按证件号匹配), 增保→不存在则新增/已存在跳过
- 不改变Excel字段结构, 只填: 姓名/证件号码/年龄(从身份证算)/所属公司
- `sync_excel_from_json()` 从 extraction_results.json 读取

### web_app/server.py 集成
- 启动时自动 `session_manager.start()`, 关闭时 `stop()`
- `GET /api/session/status` - 检查会话状态
- `POST /api/sync-excel` - 同步最近提取结果到 Excel 模板
- Excel模板路径: `C:/insurance-automation/最新保险数据下载模板.xlsx`

### Excel同步自动备份
- 同步前自动复制 `_backup.xlsx`，再写原文件
- 返回值新增 `backup_path` 字段

## 新增模块：全链路 Pipeline (LangGraph)

### 架构设计
各阶段分离为独立工具函数，可单独测试，组装成 StateGraph 运行图：
```
START → upload → extract → sync_excel → upload_erp → END
         |          |           |            |
         ↓ error    ↓ error     ↓ error      ↓ error
        END        END          END          END
```

- `insurance_agent/tools/erp_uploader.py` — ERP上传工具函数
