- 对策：多页投票 + 冲突标记 + 人工核对，**不做静默覆盖**

## 服务重启（SYSTEM 身份进程无法终止的解法）
- 8765 由 SYSTEM 身份 watchdog 拉起（链：pythonw→watchdog→server）
- `taskkill /F` → 拒绝访问；`OpenProcess` → 失败；
  提权到 Administrator 后 `AdjustTokenPrivileges` 返回 **1300 ERROR_NOT_ALL_ASSIGNED**
  （该系统未给管理员令牌分配 SeDebugPrivilege）
- **可行方案**：注册一次性 **SYSTEM 计划任务**执行终止脚本
  → `Register-ScheduledTask`（PowerShell cmdlet，走 COM API）
  → ⚠️ `schtasks.exe` 被 Program Blacklist 阻止，但 cmdlet 不受影响
  → ⚠️ `.ps1` 必须**纯 ASCII**（PowerShell 5.1 按 GBK 读，中文乱码破坏引号 → ParserError）
  → watchdog 检测到 `proc.poll() != None` → 3 秒后自动拉起新进程
- 新增 `tools/system_restart_service.py` + `.ps1`（正式工具）
- 修复 `tools/restart_service_8765.py`：纯 ctypes 启用 SeDebugPrivilege（无 pywin32 依赖，
  两个 venv 都没装）+ 修 GBK 控制台 print emoji 崩溃
