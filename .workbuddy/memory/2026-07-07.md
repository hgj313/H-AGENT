# 2026-07-07 工作日志

## 身份证号脱敏补全功能

### 背景
用户指出之前的"MiniMax PII 脱敏"问题实际是 PDF 本身对身份证号脱敏，
要求增加根据出生日期补全身份证号的功能。

### 完成事项
1. 新增 `tools/id_reconstructor.py` — 身份证号补全工具
   - `calculate_checksum()`: GB11643 校验码算法（权重 [7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2]）
   - `parse_birth_date()`: 支持 YYYY-MM-DD / YYYYMMDD / YYYY年MM月DD日 / YYYY/MM/DD
   - `reconstruct_masked_id()`: 用出生日期填充 * 位（第7-14位），重算校验码（第18位）
   - `reconstruct_persons_ids()`: 批量补全 InsuredPerson 列表
2. `InsuredPerson` 新增 `birth_date` 字段
3. OCR prompt 新增 `birth_date` 提取字段
4. `ValidatorNode` 集成补全逻辑（提取后 → 校验前自动补全）
5. `ExtractionResult.to_csv_rows()` 新增出生日期列

出生日期也全部正确提取。补全功能作为安全网，在遇到真正脱敏的 PDF 时自动激活。
