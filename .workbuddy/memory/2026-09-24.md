### 关键 bug 教训
- **partial unique index ≠ 表级 UNIQUE 约束**：SQLite `ON CONFLICT(col) WHERE ...` 的 partial index 不覆盖表 schema 上定义的 `UNIQUE(a, b)` 约束，导致 `IntegrityError('UNIQUE constraint failed: id_number, policy_number')`。
- 表级 UNIQUE 必须 `ON CONFLICT(a, b)` 显式指列。原代码 `ON CONFLICT(name, id_number)` 看似对，实际 partial index + 表级 UNIQUE 双约束让同 batch 重复行直接报 IntegrityError，整个 batch 入库失败。

### 全表 UNIQUE 约束（2026-09-24 发现）
`insurance_personnel` 表上同时存在：
- **表级** `UNIQUE(id_number, policy_number)` （DDL 字段）
- **partial unique index** `idx_person_name_id ON (name, id_number) WHERE id_number != ''`

`ON CONFLICT(name, id_number)` 只能触发 partial index，**不能捕获表级 UNIQUE 冲突** → 同 batch 内重复行 + 表级 UNIQUE 一起触发 IntegrityError。

正确做法：`ON CONFLICT(id_number, policy_number)` + Python 层 dedup。
