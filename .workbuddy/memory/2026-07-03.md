# 2026-07-03 工作日志

## 智能体功能升级：批量处理 + 增减保 + 统一CSV

### 新增功能
1. **批量上传PDF** — test_agent.py 支持多文件批量处理
2. **增减保识别** — InsuredPerson 新增 `modification_type` 字段(增保/减保)
   - InlineExtractor: 按"增加雇员信息为"/"删除雇员信息为"标记分段
   - TableExtractor: 检测"增加"/"删除"等关键词
   - OCRExtractor: prompt 增加 modification_type 字段
3. **统一CSV表格** — 所有被保人汇总到一个CSV
   - 列: 姓名/证件号码/出生日期/所属公司/批改类型/起始时间/起止时间/保险公司/保单号/来源文件

### 重大改进
- InlineExtractor 重写: 两步匹配法(先定位雇员姓名,再查找身份证号)
  - 支持粤灿批单格式(证件号码:标签, 实际用工单位:标签, 批改生效日期:标签)
  - 支持跨行工种名称提取(物业园林绿\n化工人 → 物业园林绿化工人)
- company_extractor: 增加误报黑名单(本公司/保险公司等), 改进遍历搜索
- date_parser: 支持单位数月日(如7月1日)和冒号时间格式
- table_extractor: 工种误报过滤(排除保险人/投保人等)
- pymupdf_parser: 增加中国人寿财产保险等更多保险公司识别模式
- metadata_extractor: 增加"被保险人名单"清单标记
