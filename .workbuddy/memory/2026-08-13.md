### 签名算法（逆向官网前端 umi.js 得到）★重要
- 需要 X-Timestamp / X-Nonce / X-Sign 签名头
- `X-Timestamp` = String(Date.now()) 毫秒时间戳
- `X-Nonce` = 8字节随机数 hex（16字符）
- `message` = timestamp + nonce + data_str（GET 请求 data_str 为空；POST JSON 为 JSON.stringify(body)）
- `X-Sign` = HMAC-SHA256(message, SECRET_KEY) 的 hex
- **SECRET_KEY = `c1744f81678da7aa5fca887c18df464ba54dada867bc0b3600ee73958d727377`**（官网前端硬编码）
- 登录接口 `/api/doLogin` 不需要签名，只需 JSESSIONID cookie
